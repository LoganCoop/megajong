# Megajong

A Balatro-style roguelike deckbuilder built around mahjong. Made with Godot 4.3+.

## Layout

- `scenes/` – scenes (`main.tscn` is the entry point)
- `scripts/` – GDScript (`autoload/` holds global singletons)
- `assets/` – art, audio, fonts
- `resources/` – custom `Resource` data (tiles, jokers, etc.)
